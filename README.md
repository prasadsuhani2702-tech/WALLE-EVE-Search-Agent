# WALL-E and EVE Autonomous Search Agent

## About the Project
This project uses Python to simulate WALL-E searching for EVE on a 10 × 10 grid. WALL-E uses sensor signals and probability calculations to predict EVE's location.

## Features
- Random placement of EVE
- Noisy sensor signals
- Probability-based location prediction
- Automatic movement toward the predicted location
- Prediction error calculation

## Technologies Used
- Python
- Math module
- Random module

## How to Run
1. Install Python 3.
2. Download the project.
3. Open a terminal in the project folder.
4. Run:
